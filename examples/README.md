# 견적서 템플릿 예시

CLAUDE.md의 "견적서 작성 7대 규칙"을 그대로 반영한, 현재 실무에서 쓰는 최신 시각 양식(Slate `#1e293b` +
색 액센트 1종, Pretendard 폰트, 카드형 작업범위, 결제 플로우 다이어그램)의 예시본이다.

**전부 가상의 프로젝트명·금액·의뢰인으로 구성된 샘플이며, 실제 클라이언트 정보는 일절 포함하지 않는다.**
실제 발송용 견적서(클라이언트명·실금액·실 스코프 포함)는 `output/`에 생성되며 `.gitignore`로 항상 저장소에서
제외된다 — 이 폴더의 파일들만 저장소에 커밋되는 유일한 견적서 산출물이다.

| 파일 | 문서 유형 | 규칙 반영 포인트 |
|---|---|---|
| `01_kmong-standard_견적서_예시` | 일반 크몽·위시켓 견적서 | 선금50/잔금50, VAT 별도 표기 없이 포함가 총액만, 개발자 소개 + 포트폴리오 섹션 포함, `pysirlabs.com` 자유 기재 |
| `02_kmong-enterprise_견적서_예시` | 크몽 엔터프라이즈 견적서 | 위와 동일한 결제 구조이나 개발자 소개·포트폴리오 섹션 제외, URL은 `?from=kmong` 하나만 |
| `03_direct-contract_견적서_예시` | 외부거래(직접계약) 견적서 | 공급가액/부가세(10%)/합계 itemize, 5:3:2 분할결제, 서명란 — `[ ]` 표시는 실제 발송 전 공급자 정보로 교체 |

각 문서는 `.html`(Puppeteer 렌더 원본)과 `.pdf`(변환 결과물) 쌍으로 제공한다. 새 견적서를 만들 때는
해당 유형과 가장 가까운 예시 HTML을 베이스로 복사한 뒤 프로젝트명·금액·스코프만 교체하면 된다
(CLAUDE.md 규칙 7 "직전에 사용자 승인된 generator 양식을 베이스로 복사").

재생성:

```bash
node src/utils/html2pdf.js examples/01_kmong-standard_견적서_예시.html examples/01_kmong-standard_견적서_예시.pdf
```
