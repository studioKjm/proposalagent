# Proposal Skill - 견적서 생성 스킬

## 개요
이 스킬은 IT 개발 프로젝트의 전문 견적서를 생성합니다.

## 사용법

### 기본 사용
```
/proposal
```
대화형으로 프로젝트 정보를 수집하여 견적서를 생성합니다.

### 파일 기반
```
/proposal --file [RFP파일경로]
```
RFP 파일을 분석하여 견적서를 생성합니다.

### 직접 입력
```
/proposal --project "프로젝트명" --type "web" --duration "3개월"
```

## 실행 흐름

```
1. 정보 수집
   ├─ 대화형: AskUserQuestion으로 정보 수집
   ├─ 파일: RFP 파일 분석
   └─ 직접: 파라미터에서 추출
          ↓
2. Analyzer Agent 호출
   └─ 요구사항 분석 및 구조화
          ↓
3. Estimator Agent 호출
   └─ 공수/비용 산정
          ↓
4. Writer Agent 호출
   └─ HTML 견적서 생성
          ↓
5. PDF Skill 호출 (선택)
   └─ PDF 변환
          ↓
6. 결과 출력
   └─ output/ 디렉토리에 저장
```

## 수집 정보

### 필수 정보
- **프로젝트명**: 프로젝트의 공식 명칭
- **프로젝트 유형**: web / mobile / fullstack / maintenance
- **주요 기능**: 핵심 기능 목록 (최소 1개)
- **예상 기간**: 프로젝트 기간 (주/월 단위)

### 선택 정보
- **클라이언트 정보**: 회사명, 담당자, 연락처
- **기술 스택**: 선호 기술 (없으면 자동 추천)
- **예산 범위**: 클라이언트 예산 (맞춤 조정용)
- **특이사항**: 필수 조건, 제외 사항

## 대화형 질문 순서

### Q1. 프로젝트 유형
```
어떤 유형의 프로젝트인가요?
1. 웹 개발 (웹사이트, 웹 애플리케이션)
2. 모바일 앱 (iOS, Android, 크로스플랫폼)
3. 풀스택 (웹 + 백엔드 통합)
4. 유지보수 (기존 시스템 개선)
```

### Q2. 프로젝트명 및 설명
```
프로젝트명과 간단한 설명을 알려주세요.
예: "헬스케어 예약 앱 - 사용자가 운동 프로그램을 예약하고 결제할 수 있는 모바일 앱"
```

### Q3. 주요 기능
```
구현해야 할 주요 기능을 알려주세요. (쉼표로 구분)
예: 회원가입/로그인, 예약 시스템, 결제 연동, 관리자 페이지
```

### Q4. 기술 스택 (선택)
```
선호하는 기술 스택이 있나요?
- 프론트엔드: React / Vue / Next.js / Flutter
- 백엔드: Node.js / Python / Java
- 없으면 '자동 추천'이라고 입력해주세요.
```

### Q5. 예상 기간
```
예상 개발 기간은 얼마인가요?
1. 1개월 미만
2. 1~2개월
3. 2~3개월
4. 3~6개월
5. 6개월 이상
```

### Q6. 예산 범위 (선택)
```
예상 예산 범위를 알려주세요.
1. 500만원 미만
2. 500~1000만원
3. 1000~3000만원
4. 3000~5000만원
5. 5000만원 이상
6. 예산 미정
```

### Q7. 클라이언트 정보 (선택)
```
클라이언트 정보를 알려주세요. (생략 가능)
- 회사명:
- 담당자:
- 이메일:
```

## 기본값

### 공급자 정보 기본값
```json
{
  "name": "개발 전문가",
  "ceo": "-",
  "bizNo": "-",
  "phone": "-",
  "email": "-"
}
```
*실제 사용 시 사용자 정보로 교체 필요*

### 포함 사항 기본값
```
- 상기 명시된 모든 개발 작업
- 소스코드 및 산출물 일체
- 납품 후 1개월 무상 하자보수
- 기술 문서 및 사용 가이드
- 배포 지원
```

### 미포함 사항 기본값
```
- 서버/호스팅 비용
- 도메인 비용
- 외부 API 사용료 (결제, SMS 등)
- 앱스토어 등록 비용
- 추가 기능 개발
- 콘텐츠 제작 (이미지, 텍스트)
```

## 출력 파일

### HTML 견적서
```
output/proposal-{프로젝트명}-{YYYYMMDD}.html
```

### PDF 견적서 (pdf-skill 연계)
```
output/proposal-{프로젝트명}-{YYYYMMDD}.pdf
```

### 데이터 파일 (백업용)
```
output/proposal-{프로젝트명}-{YYYYMMDD}.json
```

## 에러 처리

### 필수 정보 누락
- 최소 필수 정보 없이는 진행 불가
- 누락된 정보에 대해 재질문

### 비용 산정 실패
- 기본값으로 대체 후 경고 표시
- 수동 조정 옵션 제공

### 템플릿 오류
- 기본 텍스트 형식으로 폴백
- 오류 내용 로그 출력
