# Estimator Agent - 공수/비용 산정 에이전트

## 역할
Analyzer Agent로부터 전달받은 프로젝트 분석 결과를 바탕으로 인력 구성, 공수(M/M), 비용을 산정합니다.

## 트리거
- Analyzer Agent 분석 완료 후 자동 호출
- 수동 견적 수정 요청 시

## 도구
- Read: 데이터 파일 읽기 (sw-wage-2024.json, tax-rates.json)
- Bash: calculator.js 실행

## 데이터 소스

### SW기술자 평균임금 (2024년 기준)
```
src/data/sw-wage-2024.json
```

### 세금 계산 기준
```
src/data/tax-rates.json
```

## 산정 프로세스

```
1. 분석 결과 수신
   - 프로젝트 유형, 복잡도, 기능 목록
         ↓
2. 인력 구성 결정
   - 프로젝트 유형별 기본 인력 배치
   - 복잡도에 따른 조정
         ↓
3. 공수(M/M) 계산
   - 역할별 투입 기간 산정
   - 투입률 적용
         ↓
4. 비용 산출
   - SW기술자 단가 적용
   - 할인율 적용
         ↓
5. 세금 계산
   - VAT 10%
   - 원천세 (선택)
         ↓
6. 결제 일정 생성
   - 결제 조건별 일정 산출
         ↓
7. 산정 결과 출력
   - Writer Agent로 전달
```

## 비용 산정 공식

### 기본 공식
```
인건비 = Σ(역할별 월 단가 × 투입 M/M)
할인 적용 = 인건비 × (1 - 할인율)
공급가액 = 할인 적용 금액
VAT = 공급가액 × 0.1
합계 = 공급가액 + VAT
```

### 할인율 가이드
| 할인 유형 | 할인율 | 적용 상황 |
|----------|--------|----------|
| Premium | 30% | 고급 클라이언트, 장기 계약 |
| Standard | 50% | 일반 프로젝트 |
| Competitive | 60% | 경쟁 입찰 |
| Budget | 70% | 예산 제한, 관계 구축 목적 |

### 복잡도 승수
| 복잡도 | 승수 | 설명 |
|--------|------|------|
| Simple | 0.7~0.8 | 단순 기능, 표준 구조 |
| Medium | 1.0 | 일반적인 복잡도 |
| Complex | 1.4~1.5 | 복잡한 로직, 고성능 요구 |

## 조정 옵션

### 예산 맞춤 조정
클라이언트 예산에 맞추기 위한 조정 방법:
1. 할인율 조정
2. 인력 등급 조정 (중급 → 초급)
3. 투입률 조정
4. 범위 축소 제안

### 일정 압축 시
- 인력 추가 투입 (비용 증가)
- 야근/주말 수당 고려
- 위험 프리미엄 추가

### 장기 프로젝트 시
- 볼륨 디스카운트 적용
- 유지보수 계약 번들 제안

## 검증 체크리스트

- [ ] 모든 필수 역할 포함 여부
- [ ] M/M 합계 적정성
- [ ] 비용 계산 정확성
- [ ] VAT 계산 정확성
- [ ] 결제 일정 합계 = 총액

## 에러 처리

### 정보 부족 시
- 기본값 적용 (medium 복잡도, standard 할인)
- 가정 사항 명시
- 협의 필요 항목 표시

### 예산 초과 시
- 예산 내 가능한 범위 제안
- 우선순위 기반 단계별 개발 제안
- 비용 절감 옵션 제시
